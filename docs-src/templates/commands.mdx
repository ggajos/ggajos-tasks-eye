All Tasks Eye actions are available from Obsidian's command palette. Search for
**Tasks Eye** to find them. Tasks Eye does not assign default hotkeys, avoiding
conflicts with Obsidian and other plugins.

To use the recommendations below:

1. Open **Settings → Hotkeys**.
2. Search for the full Tasks Eye command name.
3. Select the plus button and press the recommended combination.

The recommendations are only a starting point. Choose different combinations
when they fit your vault or operating system better.
