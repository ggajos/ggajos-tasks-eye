<div class="overview-lede">
  You already know how to put tasks in Obsidian. The harder part is returning
  to a vault full of notes and knowing which ones need your attention right now.
</div>

Tasks Eye turns your notes into an organized, daily task board. Each row represents a
note, and the earliest unchecked task becomes the visible next action. The note's folder tells you the context. When you are unsure what to do next, run
[**Tasks Eye: Show Focus**](reference/commands/#open-focus).

Your Markdown remains the source of truth. Tasks Eye reads and updates the same
checkboxes and dates you already use with the Obsidian Tasks plugin; it does not
create a separate task database.

### How to read Focus

<ol class="overview-anatomy">
  <li>
    <strong>Start with the top row.</strong>
    <span>Focus only shows work due today or overdue, ordered by date.</span>
  </li>
  <li>
    <strong>Read one row as one note.</strong>
    <span>The bold text is the earliest unchecked task; the note title underneath opens the surrounding document.</span>
  </li>
  <li>
    <strong>Use Open for future work.</strong>
    <span>The Open view groups all upcoming tasks by due date, keeping them out of your immediate Focus list.</span>
  </li>
  <li>
    <strong>Use folders as contexts.</strong>
    <span>The label on the right comes from the note's folder. Filter by these folders when you want to focus on a specific project or area.</span>
  </li>
</ol>

## Act from the board—or open the note

<figure class="overview-shot overview-shot--controls">
  <img src="assets/features/actions-board-task-controls/dark-minimal/controls.png" alt="A Tasks Eye row with controls for completing a task or moving its date" loading="lazy" />
  <figcaption>
    Hover or focus a row to reveal the checkmark and ±1/±7 day rescheduling controls. Every change is
    written back to the original Tasks checkbox.
  </figcaption>
</figure>

If the next action is simple, complete or reschedule it without leaving
Focus. If you need more context, meeting notes, or links, click the note title to open it and work with the task in its full environment.

## Inbox catches metadata issues

<figure class="overview-shot overview-shot--inbox">
  <img src="assets/features/views-inbox/dark-minimal/repair-queue.png" alt="Tasks Eye Inbox showing several realistic notes with missing metadata" loading="lazy" />
  <figcaption>
    Inbox highlights notes missing required metadata so you can fix them.
  </figcaption>
</figure>

Focus and Open rely on your notes having clear dates and tasks.
Inbox finds the exceptions: an overdue or missing task date, an open note with
no unchecked tasks, an unsupported status, or a note that still needs a context
folder. Clear these validation issues to ensure your work views stay accurate.

## A simple daily workflow

1. Run [**Tasks Eye: Show Focus**](reference/commands/#open-focus) and manage today's tasks: complete, reschedule, or close them.
2. Run [**Tasks Eye: Show Inbox**](reference/commands/#open-inbox) to fix any missing dates or missing folders.
3. Use **Open** to plan ahead and **Done** when you want to look back.

The deeper reference explains [how Focus behaves](features/views-focus/),
[how Open supports planning](features/views-open/),
[how notes participate in the workflow](features/data-vault-conventions/), and
[all commands and recommended hotkeys](reference/commands/).
