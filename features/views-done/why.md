## Why Done Exists

Completed work is useful after the checkbox changes. Done gives that history a
focused view where the user can review a day, switch dates, and see the work
grouped by the same contexts used on the boards without opening another view.

The view reads completion dates from Tasks metadata so it does not need a
separate history log. A "Show Future" toggle extends the day's history with any
unfinished tasks that carry a future due date, so the view doubles as an
overview of what happened and what is coming. Subtask nesting is reproduced
using Tasks' emoji format, so completed subtasks stay under their parent instead
of collapsing into a flat list.
