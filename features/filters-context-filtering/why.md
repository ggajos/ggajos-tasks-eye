## Review one area at a time

In a tree such as Home → Work → Meeting, **Work** is the context for both
Work and Meeting. Select Work in the toolbar to review that branch in Focus,
Open, Inbox, or Done.

Select the root note's name, such as Home, to return to the whole tree.
If there is no unique indexed root, the global option is `*`.
If a previously selected context no longer exists, the filter returns to the
global option.

Moving a note between included folders does not change its context. Changing
its parent link can. Filtering changes what you see without editing any notes.

The **OOO** option shows availability markers in Focus and Open.
Selecting a normal context hides those markers.

## Know what the filter leaves out

When your selected context hides matching notes, a small informational line
below the toolbar tells you how many: **2 notes hidden by the Work filter**.
It has no buttons or links; use the existing context selector to change what
you see.

The count is specific to the current view: today's and overdue notes in Focus,
open notes in Open, notes needing repair in Inbox, and notes with completions
on the selected date in Done. A note counts once, even if it has several
violations or completed tasks. Availability markers are not notes and do not
contribute to the count.

If every matching note is hidden, the page says **No matching notes in Work.**
instead of showing an all-clear celebration. The informational line disappears
when no matching notes are hidden, including when you select the whole tree.
Folder location does not assign context: a note without an `up` link can be
hidden by a branch filter even when it lives inside that branch's folder.
