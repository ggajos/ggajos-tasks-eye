## Why reopening selected tasks exists

Completed task markers are easy to create accidentally, especially when using
keyboard shortcuts in a long note. Reopening the task should not require the
user to remember which completion-date emoji needs to be removed.

The command works directly in the editor because the user is already looking at
the specific checklist lines they want to reopen. Users can assign the
recommended hotkey to
[**Tasks Eye: Reopen selected tasks**](../../reference/commands/#uncheck-selected-tasks)
in Obsidian's Hotkeys settings.
